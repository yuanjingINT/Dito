## 专业·Arch — arch更新报错说key无效怎么解决

This is an archlinux-keyring issue. Your keyring (usually /var/lib/keyring) has expired keys or been deleted, so the cryptoversion server thinks they are invalid and refuses to sign your packages. Run:
```
sudo pacman -Syu
```
then reboot if needed. If it still fails with "Keychain missing", check that `/var/log/keys.d` exists and list expired entries; add them manually with `pacman-kyal --expire <date>`. The most common cause is one of those old expired files you just forgot about.
