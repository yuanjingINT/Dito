安装一个启动器就行，推荐hmcl、prism launcher、xmcl。

补充说明：

* Minecraft Java 版原生支持 Linux（Windows/macOS/Linux 三端），上述启动器直接安装即可游玩。基岩版（Bedrock）由于依赖 UWP 应用框架，Linux 上无法原生运行，只有 ChromeOS 设备可通过 Google Play 安装安卓版基岩版。

* Java 版对 Java 运行时的版本要求：1.17+ 需要 Java 17，1.20.5+ 需要 Java 21。HMCL、Prism Launcher 都能自动检测并按游戏版本建议合适的 Java 路径，Prism Launcher 还能直接在软件内下载管理独立的 Java 版本，避免与系统 Java 冲突。

* HMCL（黄鱼开发）在国内社区最流行，内置 Forge、Fabric、Quilt、Optifine 一键安装，支持导入 CurseForge/Modrinth 整合包，当前稳定版为 3.5.9。Prism Launcher 是国际社区主流的开源启动器，Flatpak 包更新及时。模组加载器目前推荐 NeoForge（Forge 的社区分支）或 Fabric。
