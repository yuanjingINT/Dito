## 问题原因

华硕天选 4 锐龙版 2023 在 Niri 下关闭屏幕后会自己亮屏，是因为 "Asus WMI hotkeys" 设备在轮询主板传感器时未能被系统正确识别，导致该轮询信号被误判为一次未知的按键输入（扫描码 `240`，即十六进制 `0xf0`，被上报为 `KEY_UNKNOWN`）。合成器收到这个伪按键事件后便会唤醒屏幕。

这是一个已知问题，keycode 240 在华硕多个机型（如 TUF Gaming A15 系列等）上均有上报。

## 解决方案：屏蔽伪按键

通过 libinput 的本地设备 quirk 忽略该伪按键事件。如果你的情况和我相同，可以尝试屏蔽此按键：

1. 创建/编辑本地覆盖文件：

```
sudo vim /etc/libinput/local-overrides.quirks
```

2. 写入以下内容：

```
[Asus WMI Hotkeys Ignore Phantom]
MatchName=*Asus WMI hotkeys*
AttrEventCode=-EV_KEY:0xf0;
```

3. 重启后即可解决问题。

## 验证

可使用 `libinput quirks` 工具确认 quirk 是否已正确应用到对应设备节点：

```
libinput quirks list /dev/input/eventX
```

将 `eventX` 替换为 "Asus WMI hotkeys" 对应的 event 设备节点，可通过 `libinput list-devices` 或 `cat /proc/bus/input/devices` 查找。
