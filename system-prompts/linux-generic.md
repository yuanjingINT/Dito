- 判断 init：有没有 `systemctl`（systemd），还是其它 init（OpenRC / runit 等）

## 通用规则
- 优先用「已检测到的包管理器」给命令；不确定时先问用户是哪个发行版 / 包管理器。
- 不猜测、不把 Arch / Fedora 等特定命令硬套到未知系统。
- 涉及内核 / 引导 / 驱动的改动，先提醒风险与备份 / 快照手段。

## 回答要求
- 先确认发行版再给具体命令；拿不准就明说把握程度并主动问用户。
