加入 dito chat

自己搭的 Matrix 聊天服务器，消息端到端加密，服务器只存密文。服务器在国内，不用任何额外工具就能连。

端到端加密 自建 / 无广告 网页 + 手机 + 电脑 不用额外工具

第二步：登录聊天

电脑手机都能用，什么也不用装，三分钟就能进去。

  1. 打开 element.dito.asia，这是本服务器的网页聊天界面。服务器地址已经配好了，不用自己填。
  2. 点 登录（Sign in），不是创建账户。
  3. 用户名填刚才注册那个，比如 zhangsan，不用带 @ 和后面那截域名；密码填注册时设的。
  4. 进去就能聊天了。第一次可能提示「未验证的会话」，那是加密相关的提示，不影响用，想弄干净就翻下面问答里那一条。
用户名一旦定了，你的完整 ID 就是 @用户名:dito.asia，比如 @zhangsan:dito.asia。别人加你就是加这个 ID。

第一步：在这里注册账号

不用装东西，也不用跳去别的页面。填个用户名和密码，点一下就建好了。

3 到 32 位，只能用英文小写字母、数字、点、下划线、横线，开头得是字母或数字（大写会自动转成小写）。定了就不能改，你的完整 ID 会是 @用户名:dito.asia。
别用生日、手机号、纯数字，用密码管理器生成一个最省心。

装个客户端更好用

网页版够用，但装了 App 才有通知、语音视频和加密密钥管理。先在上面注册好账号，再在 App 里登录。

  1. 装 Element X，官方新客户端，速度最快：F-Droid ｜ GitHub 直下 APK ｜ 应用商店搜 Element X（有 Google Play 的话）。
  2. 打开后如果问服务器地址，填 dito.asia。不问就直接下一步。
  3. 已经有账号就选「登录」，填用户名和密码。还没注册的话，先去网页版注册好（看上面第一段）再回来登录。
想要界面花一点的就装 FluffyChat：F-Droid ｜ GitHub 直下 APK。Element X 闪退或装不上的话，换经典版 Element，用法一样。国产系统记得在电池设置里给它开后台白名单，不然消息会延迟。
  1. 装 FluffyChat：App Store 下载链接，官网是 fluffychat.im。
  2. 先在网页版把账号注册好（看上面第一段），再打开 App 选「登录」，用同一个用户名和密码。
  3. 如果 App 让你填服务器地址，填 dito.asia；不问就直接登录。
FluffyChat 没在中国区 App Store 上架，点链接如果提示「在你所在的国家或地区不可用」，就把 Apple ID 换到其他区（美区 / 港区都行）再装。不想换区的用下面这个中国区备选。
中国区能直接下到的 Matrix 客户端是 fairchat matrix（App Store 链接），它是 FluffyChat 的定制版，用法一样。注意别下成同名的 fairchat，那个是 Rocket.Chat 客户端，连不上这里，要选名字里带 matrix、开发者是 FAIRKOM 的那个。
还有一条零安装的路：Safari 打开 element.dito.asia，点底部分享按钮，选「添加到主屏幕」，桌面就多一个图标，功能跟 App 没区别。有外区 Apple ID 也可以装 Element X（App Store 链接）。不管用哪个客户端，登录后都要按提示把「恢复密钥」设好存好，以后换手机全靠它才能看回旧聊天记录。
  1. Windows / macOS：去 element.io/download 下安装包，认准 Element Desktop。
  2. Arch / 其他 Linux：sudo pacman -S element-desktop（官方仓库就有）；或者 Flatpak：flatpak install flathub im.riot.Riot。
  3. 想要 FluffyChat 桌面版：Flathub ｜ GitHub 安装包。
  4. 第一次打开点「编辑」把服务器改成 dito.asia，然后登录。还没账号的话，先去网页版注册（看上面第一段）。
  5. 不想装东西的话，用 Chrome 打开网页版，地址栏右边有个安装图标，点一下就能当成桌面应用用。
注册统一在网页版做最省事。各家 App 对「服务器要求注册令牌」这件事的支持程度不一样，网页版这条路是验过的。账号是通用的，任何客户端填同一个用户名密码都能登，消息会同步（加密的，服务器看不到内容）。

怎么开通知

账号登进去了，默认可能一声不响。下面三件事过一遍，通知就正常了。

第一件：让系统放行

平台要开的开关
安卓 系统设置 → 通知 → 找到 Element X / FluffyChat → 允许通知；再去「应用管理 → 电池」把它设成不受限制 / 允许后台活动。小米、华为、OPPO、vivo 这类国产系统必须开，不开的话消息会被延迟甚至根本不推。
iPhone
iPad		 设置 → 通知 → Element X / FluffyChat → 允许通知，把声音和横幅都打开；顺便把「后台 App 刷新」也打开。
电脑 第一次收到消息时系统会问要不要允许通知，点允许就是；macOS 还要去 系统设置 → 通知 → Element 里手动打开。
网页版 浏览器地址栏左边的小图标（锁或者铃铛）→ 通知 → 允许。iPhone 上想让网页版也能响，得先把页面「添加到主屏幕」（iOS 16.4 以上才支持网页通知）。

第二件：把客户端里的开关打开

  1. Element Web（网页版）：点左上角头像 → 设置 → 通知 → 打开「启用通知」，下面再去选「所有消息」还是「只算有人 @ 我」。
  2. Element X（安卓）：设置 → 通知 → 打开。
  3. FluffyChat / fairchat matrix：设置 → 通知 → 打开。
  4. 某个房间太吵、或者反而不响：进房间 → 右上角设置 → 通知 → 选「所有消息」「仅 @ 提及」还是「静音」。房间被静音了就别怪它不响。

第三件：安卓还要额外装一个「分发器」

  1. 安卓上的 Element X、FluffyChat 用的是 UnifiedPush 这套推送方式，需要一个「分发器」App 帮忙把通知从中转服务器收下来。手机上没有 Google 服务框架的话，这一步是必须的。
  2. 装一个分发器：ntfy（F-Droid 里搜 ntfy，或者应用商店搜同名），也可以装 Sunup。装完打开，允许它发通知、允许自启动。
  3. 回到聊天 App 的设置里选中这个分发器（Element X 第一次打开就会问；FluffyChat 在 设置 → 通知 里改）。
  4. 从 Google Play 装的 Element X 一般自带推送通道，可以跳过这一步；真的收不到再回来装上试试。
国产系统的省电策略是通知最大的敌人。分发器和聊天 App 都得加进「电池白名单 / 允许后台运行 / 允许自启动」，不然锁屏几分钟以后就收不到了。
做完还是收不到的话：通知延迟本身是正常的，服务器架在自己家里、走家宽，比大厂慢几秒不奇怪；突然不响了先把 App 退出来重新登录一次，这样会重新注册一遍推送；网页版关掉标签页就不提醒了，想随时收到就装 App，或者在手机浏览器里「添加到主屏幕」。

邮箱和找回密码

绑个邮箱，忘了密码自己就能重置，不用来求管理员。

绑之前先知道两件事

  1. 邮箱只用来验证身份和重置密码，服务器不会给你发「你有新消息」那种提醒邮件，不用担心被邮件轰炸。
  2. 一个邮箱只归一个账号用。拿已经被别人注册过的邮箱去注册新账号，服务器会拦下来，并给你发一封提示邮件。

怎么绑

  1. 用 element.dito.asia 网页版登录。App 里路径差不多，但网页版最不容易点错。
  2. 点左上角头像 → 所有设置，在「常规」或「账号」里找到邮箱地址（英文界面是 Email address），点添加邮箱地址。
  3. 填上邮箱，发送。信是从 no-reply@dito.asia 发过来的，主题是「[dito chat] 邮箱验证」。
  4. 打开那封信，点里面的链接。浏览器打开的页面写着 Your email has now been validated，看到它就说明绑好了，页面可以直接关掉。
  5. 回到 Element，设置里的邮箱这下就是已验证状态了。

忘了密码怎么找回

  1. 在登录页面点忘记密码（网页版在密码框下面，App 里是登录页的文字按钮）。
  2. 填上绑定的邮箱，收信，主题是「[dito chat] 密码重置」。
  3. 点信里的链接，打开的页面上还要再点一次 Confirm changing my password 按钮，光打开页面不算确认。
  4. 看到 Password reset success 就回 Element，按提示设新密码。
  5. 改完密码，之前登录过的设备会被登出，用新密码重新登录一遍就好。聊天记录不会丢，那东西锁在本机加密密钥里，跟密码不是一回事。
没绑邮箱的账号，密码只能由管理员手动重置。所以能绑就趁早绑，两分钟的事。
收不到信先做三件事：翻垃圾箱（QQ 邮箱、Outlook、Gmail 都爱把陌生域名的信丢进去）、确认邮箱没写错、把 no-reply@dito.asia 加进白名单。信偶尔要等几分钟才到，别一直点「发送」，点太勤会被服务器限制一会儿。邮件里的链接 30 分钟内有效，过期了重新申请一封就行。
想换邮箱或者不想要了：设置 → 邮箱，删掉再按上面的步骤绑新的。

常见问题

点标题展开。

为什么要注册令牌，能不能开放注册

服务器是自己家宽搭的，开放注册会被脚本刷号，刷出来的号会拿去做垃圾邀请，严重的话整个服务器会被别的服务器拉黑。所以留一道令牌当门槛，熟人之间传一下就够用。

提示注册令牌无效怎么办

两种情况：一是令牌被用完了（这是限次的），二是抄漏了字符。先确认有没有多空格，还不行就找我要个新的。

为什么推荐直接用本页的表单注册

这个表单调的就是服务器自己的注册接口，令牌由页面自己带上，你只需要填用户名和密码。手机客户端碰到「填注册令牌」这一步经常卡住或者报错，所以先在页面把账号建好、再去 App 登录最省事。

登录时提示「未验证的会话」是什么意思

这是端到端加密的机制：每台新设备都是「陌生设备」，需要你从已经登录过的设备上确认一下，或者用恢复密钥自己认领。按提示点几下就好，不影响使用。

换手机怎么把聊天记录带过去

靠恢复密钥。第一次登录时如果生成了恢复密钥而且你存下来了，新设备用这串密钥就能解锁历史记录。没存的话历史消息就解不开了，这是加密的必然结果，服务器也帮不了。

服务器管理员能看我的聊天内容吗

看不到内容。房间是端到端加密的，服务器上只有密文，管理员能看到的只有谁在哪个房间、什么时候发了消息这些元数据。代价就是密码丢了、密钥丢了，谁都救不回来。

能在手机上收到通知吗

能。系统通知权限、客户端里的通知开关、安卓再加一个推送分发器，这三样弄好就正常了，具体步骤看上面「怎么开通知」那一节。

实话实说：服务器架在自己家里、走的是家宽，通知偶尔慢几秒是正常的；国产系统的省电策略爱杀后台，把 App 加进电池白名单会好很多。

可以语音和视频通话吗

服务器上装了通话中继，同一个网络下肯定能用。跨公网打电话要看家宽那边的端口转发，不保证一次就通，遇到问题告诉我。

能和其他服务器的人聊天吗

可以，Matrix 是联邦制，理论上能和 matrix.org 上的账号互相加好友、进同一个房间。不过线路是家宽加代理，稳定性不如大厂，碰到联邦不通的情况反馈给我。

能收 QQ、微信消息吗

不能。这是个独立服务器，跟 QQ 微信不通，消息得让对面也装上客户端才收得到。
