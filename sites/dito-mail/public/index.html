怎么在设备上配置

选你的平台，照着做。所有平台用的都是同一套参数。

  1. 打开「设置」，下滑找到「邮件」，进「账户」→「添加账户」
  2. 选「其他」，再选「添加邮件账户」
  3. 姓名随便填，电子邮件填你的完整地址（比如 yourname@dito.asia），密码填注册时设的，点「下一步」
  4. 选「IMAP」。收件服务器主机名填 mail.dito.asia，用户名填完整邮箱地址（含 @dito.asia），密码再输一遍
  5. 往下填发件服务器 SMTP，主机名也是 mail.dito.asia，用户名密码同上
  6. 点右上角「存储」，完成。第一封邮件可能要等一两分钟
iOS 有时会提示「无法验证服务器身份」。这是因为填了 IP 或者证书名对不上，只要主机名填的是 mail.dito.asia 就不会出现；真遇到了点「继续」即可。
  1. 打开 Gmail，点右上角头像 → 「添加其他账户」
  2. 账户类型选「其他」
  3. 输入你的完整邮箱地址，点「下一步」，然后选「IMAP」
  4. 收件服务器：mail.dito.asia，端口 993，安全类型选 SSL/TLS
  5. 发件服务器：mail.dito.asia，端口 465，安全类型选 SSL/TLS
  6. 用户名都填完整邮箱地址，密码填你设的，点「登录」→ 允许
有些国产 ROM 的邮件 App 会强制要求 POP3，Dito 邮局不提供 POP3，只支持 IMAP。用 Gmail 客户端或者别的支持 IMAP 的 App 就行。

  2. 用户名填完整邮箱地址，密码填你设的
  3. 登录后就能收发邮件、建文件夹、管理联系人
在别人电脑上临时用，浏览器是最好的选择，用完记得退出登录。
  1. 打开 Thunderbird，进「账户设置」→「账户操作」→「添加邮件账户」
  2. 填姓名、完整邮箱地址、密码，点「手动配置」
  3. 收件：协议选 IMAP，主机名 mail.dito.asia，端口 993，连接安全性 SSL/TLS，认证方式「普通密码」
  4. 发件：主机名 mail.dito.asia，端口 465，连接安全性 SSL/TLS，认证方式「普通密码」
  5. 用户名填完整邮箱地址，点「完成」
不建议用 Outlook 客户端，它对新域名支持很差，经常连不上还报一堆错。用 Thunderbird、KMail 或者系统自带的邮件应用都行。

常见问题

提交后多久能用？

申请会先进审核队列，管理员点通过后服务器自动开号。一般几分钟，最长几小时。拿申请码在页面顶部查进度。

能收发外部邮箱吗？

收信没问题。发信到 QQ、163、Gmail 都正常。但发到微软系邮箱（Outlook、Hotmail、Live）可能会被拒，这是家庭宽带的公网 IP 没有反向解析记录导致的，属于架构限制，改不了。

一共能领几个？

同一个 IP 每天最多提交 3 次申请。要更多的话找管理员。

忘了密码怎么办？

找管理员重置，重置后要重新在客户端里更新密码。

能换成别的邮箱前缀吗？

审核通过前可以重新提交；已经开通的账号要改前缀得找管理员删掉重建。

邮件会不会丢？

服务器跑在家里的 NAS 上，没有商业级的多副本备份。重要邮件建议在客户端里本地留一份。

重要：别拿它发垃圾邮件。 整个 dito.asia 域名共用同一套发信信誉，只要你这个账号群发垃圾邮件或者被大量投诉，域名就会被拉黑名单， 之后所有用户的邮件都发不出去了。正常通信随便用，群发广告请换别的地方。
